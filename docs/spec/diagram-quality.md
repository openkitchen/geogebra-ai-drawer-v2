## Spec — Diagram Quality (Triangle Angle Sum MVP)

Scope: 本规范只针对当前 MVP 场景 `triangle-angle-sum`（平行线法）。后续场景可按同样结构扩展。

### 1) 画布与可读性基线
- **几何预设**：隐藏坐标轴/网格；保持 1:1 轴比。
- **关键点可见**：A、B、C 标签必须可见。
- **角度数值不得显示**：任何 `Angle(...)` 对象的数值标签都应隐藏，保留角弧即可。
- **文字锚点**：出现一句短文本提示（如 `∠A+∠B+∠C = 180°` 或等价表达）。

### 2) 图元最小集合（推荐）
- 点/线：A、B、C；三角形；BC 直线；过 A 与 BC 平行的直线（可命名 `l`）；AB、AC 辅助线可保留。
- 角弧：
  - `angA=Angle(B,A,C)`（内角 A）
  - `angB=Angle(C,B,A)`（内角 B）
  - `angC=Angle(A,C,B)`（内角 C）
  - `angB2=Angle(lAB,l)`（对应 ∠B）
  - `angC2=Angle(l,lAC)`（对应 ∠C）
- 文字：`Text("∠A+∠B+∠C = 180°", ...)`；可选 α/β/γ 放置在不拥挤的位置。

### 3) 拥挤/错误的判定信号（用于反馈或重试）
- 发现 Angle 对象数 > 6 时，视为可能拥挤，可提示模型“减少角对象，保留必要的对应角与内角”。
- 发现任意 Angle 对象标签仍可见（如果 API 可检测），视为不符合“隐藏数值”规则。
- 发现未显示 A/B/C 标签，可提示模型显式打开这些点的标签。
- 发现画布仍显示坐标轴/网格（在几何预设下），可提示模型不需要坐标系。

### 4) 验收要点（手工/自测）
- 视觉：无坐标轴/网格；A/B/C 清晰可见；平行线结构一眼可辨；角弧清晰；看不到度数数字的叠加。
- 文案：解释与图一致，包含 180° 的直观提示文字。
- 残留：一次失败后重画，最终画面不叠加旧图元。***

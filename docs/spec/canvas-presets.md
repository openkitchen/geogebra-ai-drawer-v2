## Spec — Canvas Presets

### 目标
- 默认画面“适合教学”：少干扰、重点突出、可读性强。
- 同一个 prompt 重试/修复后，画面保持一致（不会越来越乱）。

### 视角/坐标系
- 2D 几何为主：显示网格与坐标轴（可按产品需求调整默认开关）。
- 初次加载与“校准视角”都应设置稳定的坐标范围与比例，避免图形挤在角落。

### 标签与数值显示
- 角度对象（Angle）默认只显示弧，不显示数值标签（避免满屏 45°/60°）。
- 关键点（如 A,B,C）可显示标签；辅助点/辅助线尽量隐藏标签。
- 说明性文字（Text）尽量短，并放在不遮挡图形的位置。

### 线条样式（强调/弱化）
- 辅助线：细、浅色、虚线（必要时）。
- 关键线/边：较粗、深色、实线。
- 避免无限延长线造成干扰：能用 Segment 就用 Segment。

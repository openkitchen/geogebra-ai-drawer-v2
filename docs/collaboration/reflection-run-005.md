# Reflection Run 005 — 钝角三角形泛化

## 问题概述
- 症状：用户输入“过点 (1,1) 的钝角三角形”，Minimax 生成的三角形未必钝角或未必经过该点。
- 归因：提示中只有固定坐标示例，缺少“给定点 + 钝角顶点”泛化规则；执行层无几何校验。

## 修复措施
1) 提示层：在 `prompts/packs/base.md` 增加构造模板总则与“经过指定点 P 的钝角模板”，指导模型将用户给定点作为钝角顶点并生成安全坐标。
2) 执行层：增加 `maybeAdjustObtuseTriangle`（server/index.mjs）和 `geometry-helpers.js`，若检测到顶点不是钝角则自动调整 B/C。

## 举一反三测试用例
| ID | Prompt | 期望 | 状态 |
|----|--------|------|------|
| T1 | 过点(1,1)的钝角三角形 | 含点(1,1)，该点为钝角顶点，∠A>90° | ✅ Minimax 实测 pass |
| T2 | 钝角在 B，且经过点 (2,0) | 设 B=(2,0) 钝角；其他点确保包含 B 且 ∠B>90° | ❌ Minimax 近180°/外角，需模型自检角度 |
| T3 | 只说“画个钝角三角形，经过 (0,0)”未指明顶点 | 默认把给定点作为钝角顶点，∠A>90° | 待测 |
| T4 | “给我一个钝角三角形，点 P(3,1) 在上面” | 点 P 在某顶点或边上？需澄清；模型应先问 1 个澄清问题或默认钝角顶点=P | 待测 |
| T5 | 钝角三角形但禁止出现外角标注 | 角对象应为内角；若 Angle>180° 需改点序/用 InteriorAngles，除非用户要求外角 | 待测 |
